# UQPA

Website for UQPA at [uqpunjabi.com](https://uqpunjabi.com), served with GitHub Pages from the root of the `main` branch (the custom domain is set in `CNAME`).

- `index.html` — the "Watch this space" holding page, with the logo slowly spinning (the spin is turned off for visitors who have "reduce motion" enabled).
- `assets/uqpa-logo.png` — the logo cut out on a transparent background.
- `assets/uqpa-share.jpg` — the original square logo, used as the link-preview image.
- `assets/favicon.png`, `assets/apple-touch-icon.png` — browser tab and home-screen icons.
